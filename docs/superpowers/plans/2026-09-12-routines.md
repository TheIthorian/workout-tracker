# Routines Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Routines — named, ordered lists of exercises with per-exercise targets — end to end: schema, contract, service, REST routes, MCP tools, and a mobile-first web list + editor.

**Architecture:** Two workspace-owned tables, `routines` and `routine_exercises`. `RoutinesService` (plain class in `packages/services`) owns every read and write; each mutation returns the full `RoutineDetail` so clients refresh from one shape. The exercise list is edited two ways over REST: granular `POST`/`PATCH`/`DELETE` on one routine exercise (the web editor's save-as-you-go path) and `PUT routines/:id/exercises`, which replaces the whole ordered list in one transaction and doubles as the reorder route and the MCP `update_routine` path. A routine exercise may reference a catalog exercise (read with `scopedToWorkspaceOrGlobal`) or a workspace's own; targets are checked against the exercise's `trackingType` with the existing `@app/domain` helper. Positions are dense, 0-based, and renumbered by the service — no DB unique index on `(routine_id, position)`, because a single-statement shift would trip a non-deferrable index mid-update.

**Tech Stack:** TypeScript, NestJS + Fastify, Drizzle + Postgres, Zod, vitest + testcontainers, React + Vite + Tailwind + shadcn/ui, `framer-motion` `Reorder` (already a dependency) for drag-reorder, MCP SDK.

**Spec:** `docs/superpowers/specs/2026-09-10-workout-tracker-phase-1-design.md` — sections "`routines` and `routine_exercises`", "API", "Packages", "Web UX / Routines", "Testing". Exercises are the shared catalog + custom rows per `docs/superpowers/specs/2026-09-12-global-exercise-catalog-design.md`.

## Global Constraints

- **Never use `any`** — not in source, not in tests, no `oxlint-disable` for it. Where a cast is unavoidable use `as unknown as X`.
- **`type` over `interface`** unless a class implements it.
- **`enum` for closed sets of values** — a TypeScript enum, read by Zod via `z.enum(MyEnum)`.
- **Explicit return type on every function and method.**
- **Object arguments** when a function takes two or more parameters.
- **JSDoc on every public method and exported function.** Concise.
- **Comments explain why, never what**, and never describe the change being made.
- **Helpers are declared after their caller.**
- **Never `throw new Error(...)`** — always a typed error from `@app/errors`.
- **Every workspace-scoped WRITE uses `scopedToWorkspace(table, workspaceId, ...filters)`.** Reads that must admit catalog exercises use `scopedToWorkspaceOrGlobal` on the `exercises` table only. Never a hand-written `eq(table.workspaceId, id)` alongside other filters.
- **Every service method calls `membership.require({ userId, workspaceId })` before its query.**
- **A caller who may not see a workspace gets `EntityNotFoundError` (404), never 403.** An exercise id the workspace cannot see (other tenant, or archived) is also a 404 when assigned to a routine.
- **Canonical units only:** kilograms, metres, seconds. No unit conversion server-side.
- **Libraries never read `process.env`.**
- **Formatting:** 4-space indent, single quotes, 120 cols, trailing commas. Run `pnpm format` before each commit.
- **Blank line before and after every log statement, and after a closing scope brace.**
- **Migrations:** `pnpm --filter @app/db db:generate` after any schema change; read the SQL before committing; this plan's migration is purely additive (two `CREATE TABLE`s plus constraints/indexes) — anything else in it is a bug.
- **`route-guard-coverage.e2e.spec.ts`:** only `MCP_TOKEN_ROUTES` grows, and only with the five routes the MCP tools in Task 5 actually call.
- **Commits:** Conventional Commits, ending with the attribution lines the session provides.

```ts
import { sql } from 'drizzle-orm';
import { check, foreignKey, index, integer, numeric, pgTable, text, timestamp, uuid } from 'drizzle-orm/pg-core';
import { user } from './auth.js';
import { exercises } from './exercises.js';
import { workspaces } from './workspaces.js';

/**
 * A template for a workout: a name and an ordered list of exercises with targets. Starting a
 * session copies the list rather than referencing it, so a routine can be edited freely without
 * rewriting history — which is also why routines are archived, never deleted.
 */
export const routines = pgTable(
    'routines',
    {
        id: uuid('id').primaryKey().defaultRandom().notNull(),
        workspaceId: uuid('workspace_id').notNull(),
        createdByUserId: uuid('created_by_user_id'),
        name: text('name').notNull(),
        description: text('description'),
        archivedAt: timestamp('archived_at', { withTimezone: true, mode: 'string' }),
        createdAt: timestamp('created_at', { withTimezone: true, mode: 'string' })
            .default(sql`now()`)
            .notNull(),
        updatedAt: timestamp('updated_at', { withTimezone: true, mode: 'string' })
            .default(sql`now()`)
            .notNull(),
    },
    (table) => [
        index('routines_workspace_id_idx').using('btree', table.workspaceId.asc().nullsLast().op('uuid_ops')),
        foreignKey({
            columns: [table.workspaceId],
            foreignColumns: [workspaces.id],
            name: 'routines_workspace_id_workspaces_id_fk',
        }).onDelete('cascade'),
        foreignKey({
            columns: [table.createdByUserId],
            foreignColumns: [user.id],
            name: 'routines_created_by_user_id_user_id_fk',
        }).onDelete('set null'),
    ],
);

/**
 * One slot in a routine. The same exercise may appear more than once (drop sets, supersets), so
 * there is no uniqueness on `(routine_id, exercise_id)`. `position` is dense and 0-based, kept so by
 * the service rather than a unique index: a one-statement shift after a removal would violate a
 * non-deferrable index mid-update.
 *
 * Which `target_*` columns are meaningful follows the exercise's `tracking_type`; the service
 * rejects a mismatch, and everything is stored in canonical units (kg, m, s).
 */
export const routineExercises = pgTable(
    'routine_exercises',
    {
        id: uuid('id').primaryKey().defaultRandom().notNull(),
        workspaceId: uuid('workspace_id').notNull(),
        routineId: uuid('routine_id').notNull(),
        exerciseId: uuid('exercise_id').notNull(),
        position: integer('position').notNull(),
        targetSets: integer('target_sets').notNull(),
        restSeconds: integer('rest_seconds'),
        notes: text('notes'),
        targetReps: integer('target_reps'),
        targetWeightKg: numeric('target_weight_kg', { precision: 7, scale: 2, mode: 'number' }),
        targetDurationSeconds: integer('target_duration_seconds'),
        targetDistanceM: numeric('target_distance_m', { precision: 9, scale: 2, mode: 'number' }),
        createdAt: timestamp('created_at', { withTimezone: true, mode: 'string' })
            .default(sql`now()`)
            .notNull(),
        updatedAt: timestamp('updated_at', { withTimezone: true, mode: 'string' })
            .default(sql`now()`)
            .notNull(),
    },
    (table) => [
        index('routine_exercises_workspace_id_idx').using('btree', table.workspaceId.asc().nullsLast().op('uuid_ops')),
        index('routine_exercises_routine_id_idx').using('btree', table.routineId.asc().nullsLast().op('uuid_ops')),
        check('routine_exercises_target_sets_check', sql`${table.targetSets} >= 1`),
        check(
            'routine_exercises_targets_non_negative_check',
            sql`coalesce(${table.restSeconds}, 0) >= 0 and coalesce(${table.targetReps}, 0) >= 0 and coalesce(${table.targetWeightKg}, 0) >= 0 and coalesce(${table.targetDurationSeconds}, 0) >= 0 and coalesce(${table.targetDistanceM}, 0) >= 0`,
        ),
        foreignKey({
            columns: [table.workspaceId],
            foreignColumns: [workspaces.id],
            name: 'routine_exercises_workspace_id_workspaces_id_fk',
        }).onDelete('cascade'),
        foreignKey({
            columns: [table.routineId],
            foreignColumns: [routines.id],
            name: 'routine_exercises_routine_id_routines_id_fk',
        }).onDelete('cascade'),
        // Exercises are archived, never deleted; `restrict` makes a stray hard delete fail loudly
        // instead of silently emptying routines.
        foreignKey({
            columns: [table.exerciseId],
            foreignColumns: [exercises.id],
            name: 'routine_exercises_exercise_id_exercises_id_fk',
        }).onDelete('restrict'),
    ],
);
```

```ts
import { TrackingType } from '@app/domain';
import { z } from 'zod';
import { guidSchema, paginatedResponseSchema, paginationQuerySchema } from './primitives.js';

/** The exercise a routine slot points at — enough to render the row and pick an input widget. */
export const routineExerciseSummarySchema = z.object({
    id: guidSchema,
    name: z.string(),
    trackingType: z.enum(TrackingType),
    isCatalog: z.boolean(),
    /** Set when the exercise was archived after being added; the slot stays, flagged. */
    archivedAt: z.string().nullable(),
});

export const routineExerciseResponseSchema = z.object({
    id: guidSchema,
    position: z.number().int(),
    targetSets: z.number().int(),
    restSeconds: z.number().int().nullable(),
    notes: z.string().nullable(),
    targetReps: z.number().int().nullable(),
    targetWeightKg: z.number().nullable(),
    targetDurationSeconds: z.number().int().nullable(),
    targetDistanceM: z.number().nullable(),
    exercise: routineExerciseSummarySchema,
});

export const routineResponseSchema = z.object({
    id: guidSchema,
    name: z.string(),
    description: z.string().nullable(),
    archivedAt: z.string().nullable(),
    exerciseCount: z.number().int(),
    createdAt: z.string(),
    updatedAt: z.string(),
});

/** The routine plus its ordered exercises — what the editor and the MCP get tool read. */
export const routineDetailResponseSchema = routineResponseSchema.extend({
    exercises: z.array(routineExerciseResponseSchema),
});

export const routineListResponseSchema = paginatedResponseSchema(routineResponseSchema);

/** Query parameters for `GET /api/v1/workspaces/{workspaceId}/routines`. */
export const routineListQuerySchema = paginationQuerySchema.extend({
    search: z.string().max(200).optional(),
    includeArchived: z
        .enum(['true', 'false'])
        .optional()
        .transform((value) => value === 'true'),
});

/** The body of `POST /api/v1/workspaces/{workspaceId}/routines`. */
export const postRoutineRequestSchema = z.object({
    name: z.string().min(1, 'Name is required').max(200, 'Name must not exceed 200 characters'),
    description: z.string().max(2000).nullable().optional(),
});

/** The body of `PATCH /api/v1/workspaces/{workspaceId}/routines/{routineId}`. An omitted key leaves the stored value alone. */
export const patchRoutineRequestSchema = z
    .object({
        name: z.string().min(1).max(200).optional(),
        description: z.string().max(2000).nullable().optional(),
        archived: z.boolean().optional(),
    })
    .refine((body) => Object.keys(body).length > 0, { message: 'At least one field must be provided' });

/**
 * Targets for one routine slot. Every measurement is optional and nullable — a target is a
 * suggestion, not a requirement — and the bounds are sanity limits, not training advice. Which
 * fields fit the exercise's tracking type is checked by the service, which can see the exercise.
 */
const routineExerciseTargetsSchema = z.object({
    targetSets: z.number().int().min(1).max(100),
    restSeconds: z.number().int().min(0).max(3600).nullable().optional(),
    notes: z.string().max(1000).nullable().optional(),
    targetReps: z.number().int().min(0).max(1000).nullable().optional(),
    targetWeightKg: z.number().min(0).max(10000).nullable().optional(),
    targetDurationSeconds: z.number().int().min(0).max(86400).nullable().optional(),
    targetDistanceM: z.number().min(0).max(1000000).nullable().optional(),
});

/** The body of `POST .../routines/{routineId}/exercises`: appends a slot. */
export const postRoutineExerciseRequestSchema = routineExerciseTargetsSchema.extend({
    exerciseId: guidSchema,
    targetSets: z.number().int().min(1).max(100).default(3),
});

/**
 * The body of `PATCH .../routines/{routineId}/exercises/{routineExerciseId}`. Position is not
 * editable here — reordering goes through the PUT of the whole list.
 */
export const patchRoutineExerciseRequestSchema = routineExerciseTargetsSchema
    .partial()
    .strict()
    .refine((body) => Object.keys(body).length > 0, { message: 'At least one field must be provided' });

/** The body of `PUT .../routines/{routineId}/exercises`: the complete ordered list, replacing what was there. */
export const putRoutineExercisesRequestSchema = z.object({
    exercises: z.array(postRoutineExerciseRequestSchema).max(50),
});

export type RoutineExerciseSummary = z.infer<typeof routineExerciseSummarySchema>;
export type RoutineExerciseResponse = z.infer<typeof routineExerciseResponseSchema>;
export type RoutineResponse = z.infer<typeof routineResponseSchema>;
export type RoutineDetailResponse = z.infer<typeof routineDetailResponseSchema>;
export type RoutineListResponse = z.infer<typeof routineListResponseSchema>;
export type RoutineListQuery = z.infer<typeof routineListQuerySchema>;
export type PostRoutineRequest = z.infer<typeof postRoutineRequestSchema>;
export type PatchRoutineRequest = z.infer<typeof patchRoutineRequestSchema>;
export type PostRoutineExerciseRequest = z.infer<typeof postRoutineExerciseRequestSchema>;
export type PatchRoutineExerciseRequest = z.infer<typeof patchRoutineExerciseRequestSchema>;
export type PutRoutineExercisesRequest = z.infer<typeof putRoutineExercisesRequestSchema>;
```

```ts
import { schema, scopedToWorkspace, scopedToWorkspaceOrGlobal, withTransaction, type Db, type Tx } from '@app/db';
import { validateSetMeasurements, type TrackingType } from '@app/domain';
import { EntityNotFoundError, SetShapeMismatchError } from '@app/errors';
import { asc, count, eq, ilike, inArray, isNull, sql } from 'drizzle-orm';
import type { WorkspaceMembershipService } from './workspace-membership.service.js';

const { exercises, routineExercises, routines } = schema;

export type RoutineSummary = {
    id: string;
    name: string;
    description: string | null;
    archivedAt: string | null;
    exerciseCount: number;
    createdAt: string;
    updatedAt: string;
};

export type RoutineExerciseTargets = {
    targetSets: number;
    restSeconds: number | null;
    notes: string | null;
    targetReps: number | null;
    targetWeightKg: number | null;
    targetDurationSeconds: number | null;
    targetDistanceM: number | null;
};

export type RoutineExercise = RoutineExerciseTargets & {
    id: string;
    position: number;
    exercise: {
        id: string;
        name: string;
        trackingType: TrackingType;
        isCatalog: boolean;
        archivedAt: string | null;
    };
};

export type RoutineDetail = RoutineSummary & { exercises: RoutineExercise[] };

/** One slot as a caller supplies it: the exercise plus its targets. Omitted targets are null. */
export type RoutineExerciseInput = { exerciseId: string; targetSets: number } & Partial<
    Omit<RoutineExerciseTargets, 'targetSets'>
>;

export type PaginatedRoutines = {
    data: RoutineSummary[];
    page: number;
    pageSize: number;
    totalCount: number;
    totalPages: number;
};

/**
 * Routines and their ordered exercise slots.
 *
 * Every mutation resolves to the full `RoutineDetail`, so a client refreshes from one shape
 * whichever route it used. Slot positions are dense and 0-based and are renumbered here; nothing
 * else may write them.
 */
export class RoutinesService {
    private readonly db: Db;
    private readonly membership: WorkspaceMembershipService;

    constructor({ db, membership }: { db: Db; membership: WorkspaceMembershipService }) {
        this.db = db;
        this.membership = membership;
    }

    /**
     * A page of the workspace's routines by name, each with its slot count.
     *
     * @param search matches anywhere in the name, case-insensitively.
     * @throws EntityNotFoundError when the caller is not a member of the workspace.
     */
    async list({
        userId,
        workspaceId,
        page,
        pageSize,
        search,
        includeArchived,
    }: {
        userId: string;
        workspaceId: string;
        page: number;
        pageSize: number;
        search?: string;
        includeArchived?: boolean;
    }): Promise<PaginatedRoutines> {
        await this.membership.require({ userId, workspaceId });

        const where = scopedToWorkspace(
            routines,
            workspaceId,
            search === undefined || search === '' ? undefined : ilike(routines.name, `%${search}%`),
            includeArchived === true ? undefined : isNull(routines.archivedAt),
        );

        const [data, [totals]] = await Promise.all([
            this.db
                .select(ROUTINE_SUMMARY_COLUMNS)
                .from(routines)
                .where(where)
                .orderBy(asc(routines.name), asc(routines.createdAt))
                .limit(pageSize)
                .offset((page - 1) * pageSize),
            this.db.select({ totalCount: count() }).from(routines).where(where),
        ]);

        const totalCount = totals?.totalCount ?? 0;

        return { data, page, pageSize, totalCount, totalPages: Math.ceil(totalCount / pageSize) };
    }

    /**
     * One routine with its ordered slots.
     *
     * @throws EntityNotFoundError when the caller is not a member, or the routine is not in this
     * workspace — the two are deliberately indistinguishable on the wire.
     */
    async get({
        userId,
        workspaceId,
        routineId,
    }: {
        userId: string;
        workspaceId: string;
        routineId: string;
    }): Promise<RoutineDetail> {
        await this.membership.require({ userId, workspaceId });

        return this.loadDetail({ db: this.db, workspaceId, routineId });
    }

    /**
     * Creates an empty routine.
     *
     * @throws EntityNotFoundError when the caller is not a member of the workspace.
     */
    async create({
        userId,
        workspaceId,
        name,
        description,
    }: {
        userId: string;
        workspaceId: string;
        name: string;
        description?: string | null;
    }): Promise<RoutineDetail> {
        await this.membership.require({ userId, workspaceId });

        const [row] = await this.db
            .insert(routines)
            .values({ workspaceId, createdByUserId: userId, name, description: description ?? null })
            .returning({ id: routines.id });

        return this.loadDetail({ db: this.db, workspaceId, routineId: row.id });
    }

    /**
     * Updates a routine's own fields. Only the fields present are written.
     *
     * @param archived true archives the routine, false restores it.
     * @throws EntityNotFoundError when the caller is not a member, or the routine is not in this
     * workspace.
     */
    async update({
        userId,
        workspaceId,
        routineId,
        name,
        description,
        archived,
    }: {
        userId: string;
        workspaceId: string;
        routineId: string;
        name?: string;
        description?: string | null;
        archived?: boolean;
    }): Promise<RoutineDetail> {
        await this.membership.require({ userId, workspaceId });

        const now = new Date().toISOString();

        const [row] = await this.db
            .update(routines)
            .set({
                ...(name === undefined ? {} : { name }),
                ...(description === undefined ? {} : { description }),
                ...(archived === undefined ? {} : { archivedAt: archived ? now : null }),
                updatedAt: now,
            })
            .where(scopedToWorkspace(routines, workspaceId, eq(routines.id, routineId)))
            .returning({ id: routines.id });

        if (!row) throw new EntityNotFoundError('Routine not found');

        return this.loadDetail({ db: this.db, workspaceId, routineId });
    }

    /**
     * Appends a slot to the end of the routine.
     *
     * @throws EntityNotFoundError for a routine not in this workspace, or an exercise the workspace
     * cannot see (another tenant's, or archived).
     * @throws SetShapeMismatchError when a target does not fit the exercise's tracking type.
     */
    async addExercise({
        userId,
        workspaceId,
        routineId,
        ...input
    }: {
        userId: string;
        workspaceId: string;
        routineId: string;
    } & RoutineExerciseInput): Promise<RoutineDetail> {
        await this.membership.require({ userId, workspaceId });

        return withTransaction(this.db, async (tx) => {
            await this.requireRoutine({ db: tx, workspaceId, routineId });
            const trackingTypes = await this.requireAssignableExercises({
                db: tx,
                workspaceId,
                exerciseIds: [input.exerciseId],
            });
            assertTargetsFit({ trackingType: trackingTypes.get(input.exerciseId) as TrackingType, targets: input });

            const [{ next }] = await tx
                .select({ next: sql<number>`coalesce(max(${routineExercises.position}) + 1, 0)`.mapWith(Number) })
                .from(routineExercises)
                .where(scopedToWorkspace(routineExercises, workspaceId, eq(routineExercises.routineId, routineId)));

            await tx.insert(routineExercises).values(toSlotRow({ workspaceId, routineId, position: next, input }));

            return this.loadDetail({ db: tx, workspaceId, routineId });
        });
    }

    /**
     * Updates one slot's targets. Only the fields present are written; the merged result is
     * re-checked against the exercise's tracking type.
     *
     * @throws EntityNotFoundError when the slot is not in this routine and workspace.
     * @throws SetShapeMismatchError when a target does not fit the exercise's tracking type.
     */
    async updateExercise({
        userId,
        workspaceId,
        routineId,
        routineExerciseId,
        ...patch
    }: {
        userId: string;
        workspaceId: string;
        routineId: string;
        routineExerciseId: string;
    } & Partial<RoutineExerciseTargets>): Promise<RoutineDetail> {
        await this.membership.require({ userId, workspaceId });

        return withTransaction(this.db, async (tx) => {
            const [current] = await tx
                .select({
                    targetSets: routineExercises.targetSets,
                    restSeconds: routineExercises.restSeconds,
                    notes: routineExercises.notes,
                    targetReps: routineExercises.targetReps,
                    targetWeightKg: routineExercises.targetWeightKg,
                    targetDurationSeconds: routineExercises.targetDurationSeconds,
                    targetDistanceM: routineExercises.targetDistanceM,
                    trackingType: exercises.trackingType,
                })
                .from(routineExercises)
                .innerJoin(exercises, eq(exercises.id, routineExercises.exerciseId))
                .where(
                    scopedToWorkspace(
                        routineExercises,
                        workspaceId,
                        eq(routineExercises.routineId, routineId),
                        eq(routineExercises.id, routineExerciseId),
                    ),
                );

            if (!current) throw new EntityNotFoundError('Routine exercise not found');

            const merged: RoutineExerciseTargets = {
                targetSets: patch.targetSets ?? current.targetSets,
                restSeconds: patch.restSeconds === undefined ? current.restSeconds : patch.restSeconds,
                notes: patch.notes === undefined ? current.notes : patch.notes,
                targetReps: patch.targetReps === undefined ? current.targetReps : patch.targetReps,
                targetWeightKg: patch.targetWeightKg === undefined ? current.targetWeightKg : patch.targetWeightKg,
                targetDurationSeconds:
                    patch.targetDurationSeconds === undefined
                        ? current.targetDurationSeconds
                        : patch.targetDurationSeconds,
                targetDistanceM: patch.targetDistanceM === undefined ? current.targetDistanceM : patch.targetDistanceM,
            };
            assertTargetsFit({ trackingType: current.trackingType, targets: merged });

            await tx
                .update(routineExercises)
                .set({ ...merged, updatedAt: new Date().toISOString() })
                .where(
                    scopedToWorkspace(
                        routineExercises,
                        workspaceId,
                        eq(routineExercises.routineId, routineId),
                        eq(routineExercises.id, routineExerciseId),
                    ),
                );

            return this.loadDetail({ db: tx, workspaceId, routineId });
        });
    }

    /**
     * Removes a slot and closes the gap in the remaining positions.
     *
     * @throws EntityNotFoundError when the slot is not in this routine and workspace.
     */
    async removeExercise({
        userId,
        workspaceId,
        routineId,
        routineExerciseId,
    }: {
        userId: string;
        workspaceId: string;
        routineId: string;
        routineExerciseId: string;
    }): Promise<RoutineDetail> {
        await this.membership.require({ userId, workspaceId });

        return withTransaction(this.db, async (tx) => {
            const deleted = await tx
                .delete(routineExercises)
                .where(
                    scopedToWorkspace(
                        routineExercises,
                        workspaceId,
                        eq(routineExercises.routineId, routineId),
                        eq(routineExercises.id, routineExerciseId),
                    ),
                )
                .returning({ id: routineExercises.id });

            if (deleted.length === 0) throw new EntityNotFoundError('Routine exercise not found');

            const remaining = await tx
                .select({ id: routineExercises.id, position: routineExercises.position })
                .from(routineExercises)
                .where(scopedToWorkspace(routineExercises, workspaceId, eq(routineExercises.routineId, routineId)))
                .orderBy(asc(routineExercises.position));

            for (const [index, slot] of remaining.entries()) {
                if (slot.position === index) continue;

                await tx
                    .update(routineExercises)
                    .set({ position: index })
                    .where(scopedToWorkspace(routineExercises, workspaceId, eq(routineExercises.id, slot.id)));
            }

            return this.loadDetail({ db: tx, workspaceId, routineId });
        });
    }

    /**
     * Replaces the routine's whole slot list with `exercises`, in the given order, as one
     * transaction: an invalid slot anywhere leaves the old list untouched.
     *
     * @throws EntityNotFoundError for a routine not in this workspace, or any exercise the
     * workspace cannot see.
     * @throws SetShapeMismatchError when any slot's targets do not fit its exercise.
     */
    async replaceExercises({
        userId,
        workspaceId,
        routineId,
        exercises: inputs,
    }: {
        userId: string;
        workspaceId: string;
        routineId: string;
        exercises: RoutineExerciseInput[];
    }): Promise<RoutineDetail> {
        await this.membership.require({ userId, workspaceId });

        return withTransaction(this.db, async (tx) => {
            await this.requireRoutine({ db: tx, workspaceId, routineId });
            const trackingTypes = await this.requireAssignableExercises({
                db: tx,
                workspaceId,
                exerciseIds: inputs.map((input) => input.exerciseId),
            });

            for (const input of inputs) {
                assertTargetsFit({ trackingType: trackingTypes.get(input.exerciseId) as TrackingType, targets: input });
            }

            await tx
                .delete(routineExercises)
                .where(scopedToWorkspace(routineExercises, workspaceId, eq(routineExercises.routineId, routineId)));

            if (inputs.length > 0) {
                await tx
                    .insert(routineExercises)
                    .values(inputs.map((input, position) => toSlotRow({ workspaceId, routineId, position, input })));
            }

            await tx
                .update(routines)
                .set({ updatedAt: new Date().toISOString() })
                .where(scopedToWorkspace(routines, workspaceId, eq(routines.id, routineId)));

            return this.loadDetail({ db: tx, workspaceId, routineId });
        });
    }

    private async requireRoutine({
        db,
        workspaceId,
        routineId,
    }: {
        db: Db | Tx;
        workspaceId: string;
        routineId: string;
    }): Promise<void> {
        const [row] = await db
            .select({ id: routines.id })
            .from(routines)
            .where(scopedToWorkspace(routines, workspaceId, eq(routines.id, routineId)));

        if (!row) throw new EntityNotFoundError('Routine not found');
    }

    /**
     * The tracking type of every exercise in `exerciseIds`, provided each is one the workspace can
     * see (its own or catalog) and not archived. Any miss is a not-found for the whole call.
     */
    private async requireAssignableExercises({
        db,
        workspaceId,
        exerciseIds,
    }: {
        db: Db | Tx;
        workspaceId: string;
        exerciseIds: string[];
    }): Promise<Map<string, TrackingType>> {
        const unique = [...new Set(exerciseIds)];
        if (unique.length === 0) return new Map();

        const rows = await db
            .select({ id: exercises.id, trackingType: exercises.trackingType })
            .from(exercises)
            .where(
                scopedToWorkspaceOrGlobal(
                    exercises,
                    workspaceId,
                    inArray(exercises.id, unique),
                    isNull(exercises.archivedAt),
                ),
            );

        if (rows.length !== unique.length) throw new EntityNotFoundError('Exercise not found');

        return new Map(rows.map((row) => [row.id, row.trackingType]));
    }

    private async loadDetail({
        db,
        workspaceId,
        routineId,
    }: {
        db: Db | Tx;
        workspaceId: string;
        routineId: string;
    }): Promise<RoutineDetail> {
        const [routine] = await db
            .select(ROUTINE_SUMMARY_COLUMNS)
            .from(routines)
            .where(scopedToWorkspace(routines, workspaceId, eq(routines.id, routineId)));

        if (!routine) throw new EntityNotFoundError('Routine not found');

        // The tenant filter sits on `routine_exercises`; the joined exercise row may be catalog
        // content (null workspace), which was admitted when the slot was written.
        const slots = await db
            .select({
                id: routineExercises.id,
                position: routineExercises.position,
                targetSets: routineExercises.targetSets,
                restSeconds: routineExercises.restSeconds,
                notes: routineExercises.notes,
                targetReps: routineExercises.targetReps,
                targetWeightKg: routineExercises.targetWeightKg,
                targetDurationSeconds: routineExercises.targetDurationSeconds,
                targetDistanceM: routineExercises.targetDistanceM,
                exercise: {
                    id: exercises.id,
                    name: exercises.name,
                    trackingType: exercises.trackingType,
                    isCatalog: sql<boolean>`${exercises.workspaceId} is null`,
                    archivedAt: exercises.archivedAt,
                },
            })
            .from(routineExercises)
            .innerJoin(exercises, eq(exercises.id, routineExercises.exerciseId))
            .where(scopedToWorkspace(routineExercises, workspaceId, eq(routineExercises.routineId, routineId)))
            .orderBy(asc(routineExercises.position));

        return { ...routine, exercises: slots };
    }
}

const ROUTINE_SUMMARY_COLUMNS = {
    id: routines.id,
    name: routines.name,
    description: routines.description,
    archivedAt: routines.archivedAt,
    exerciseCount:
        sql<number>`(select count(*) from ${routineExercises} where ${routineExercises.routineId} = ${routines.id})`.mapWith(
            Number,
        ),
    createdAt: routines.createdAt,
    updatedAt: routines.updatedAt,
};

/**
 * A missing target is fine — targets are suggestions — so only the `unexpected` half of the
 * domain check matters here; `missing` is what a logged set cares about.
 */
function assertTargetsFit({
    trackingType,
    targets,
}: {
    trackingType: TrackingType;
    targets: Partial<Omit<RoutineExerciseTargets, 'targetSets' | 'restSeconds' | 'notes'>>;
}): void {
    const result = validateSetMeasurements({
        trackingType,
        measurements: {
            weightKg: targets.targetWeightKg,
            reps: targets.targetReps,
            durationSeconds: targets.targetDurationSeconds,
            distanceM: targets.targetDistanceM,
        },
    });

    if (result.valid || result.unexpected.length === 0) return;

    throw new SetShapeMismatchError(
        'Targets do not match the exercise tracking type',
        `${trackingType} does not use: ${result.unexpected.join(', ')}`,
    );
}

function toSlotRow({
    workspaceId,
    routineId,
    position,
    input,

    routineId: string;

        routineId,

        position,
        targetSets: input.targetSets,

        notes: input.notes ?? null,
        targetReps: input.targetReps ?? null,
        targetWeightKg: input.targetWeightKg ?? null,
        targetDurationSeconds: input.targetDurationSeconds ?? null,

    };
}
```

```ts
    createRoutineToolArgsSchema,
    getRoutineToolArgsSchema,
    listRoutinesToolArgsSchema,
    paginationQuerySchema,
    updateRoutineToolArgsSchema,
    type RoutineDetailResponse,
    type RoutineExerciseToolInput,

import type { Logger } from '@app/logger';
import type { McpContext, ResourceUrlGenerator } from '@app/nest-common';
import { defineTool, type McpToolDefinition } from '../tool-definition.js';
import { runToolCaught, serializeToolResult } from '../tool-execution.js';
import { attachRoutineLinks } from './routine-links.js';

const TARGET_HELP =
    'Each slot names an exerciseId and optional targets: targetSets (default 3), restSeconds, notes, and ' +
    "the measurements that fit the exercise's trackingType — weight_reps: targetReps and targetWeightKg; " +
    'duration: targetDurationSeconds; distance_time: targetDistanceM and targetDurationSeconds. Units are ' +
    'kilograms, metres, and seconds. A target that does not fit the tracking type is rejected. The same ' +
    'exercise may appear more than once.';

/**
 * The workspace's routines, over the same `RoutineDetailResponse` wire shape `apps/api` serves.
 * A tool edits the exercise list by sending the whole ordered list, which `apps/api` applies as one
 * replacement — simpler for a model than diffing slot by slot.
 *
 * No tool here takes a `workspaceId`; it comes from the personal access token, same as every other
 * tool in this app - see `item.tools.ts`'s doc comment for why.
 */
export function buildRoutineTools({
    context,
    client,
    logger,
    urls,
}: {
    context: McpContext;
    client: ApiClient;
    logger: Logger;
    urls: ResourceUrlGenerator;
}): McpToolDefinition[] {
    const basePath = `/workspaces/${context.workspaceId}/routines`;

    const withLinks = <T extends { id: string }>(routine: T): T & { webUrl: string; resourceUrl: string } =>
        attachRoutineLinks({ urls, routine, workspaceId: context.workspaceId });

    const putExercises = async (
        routineId: string,
        exercises: RoutineExerciseToolInput[],
    ): Promise<RoutineDetailResponse> =>
        client.put<RoutineDetailResponse>({
            path: `${basePath}/${routineId}/exercises`,
            body: { exercises: exercises.map(toSlotBody) },
        });

    return [
        defineTool({
            methodName: 'ListRoutines',
            description:
                "Lists the token's workspace routines (workout templates) by name, with optional search and " +
                'paging. Each entry carries exerciseCount and webUrl, the routine editor in the web app. ' +
                'Archived routines are excluded unless includeArchived is set.',
            inputSchema: listRoutinesToolArgsSchema,
            handler: async (args) => {
                const pagination = paginationQuerySchema.parse({
                    page: args.page ?? undefined,
                    pageSize: args.pageSize ?? undefined,
                });

                const page = await client.get<RoutineListResponse>({
                    path: basePath,
                    query: {
                        page: pagination.page,
                        pageSize: pagination.pageSize,
                        search: args.search ?? undefined,
                        includeArchived: args.includeArchived ?? undefined,
                    },
                });

                return serializeToolResult({ body: { ...page, data: page.data.map(withLinks) } });
            },
        }),
        defineTool({
            methodName: 'GetRoutine',
            description:
                'Gets a routine by id: its name, description, and ordered exercises, each with the exercise ' +
                '(id, name, trackingType, isCatalog, archivedAt) and its targets. Includes webUrl.',
            inputSchema: getRoutineToolArgsSchema,
            handler: async (args) => {
                const routine = await client.get<RoutineDetailResponse>({ path: `${basePath}/${args.routineId}` });

                return serializeToolResult({ body: withLinks(routine) });
            },
        }),
        defineTool({
            methodName: 'CreateRoutine',
            description:
                "Creates a routine in the token's workspace, optionally with its complete ordered exercise " +
                'list. Use list_exercises to find exerciseIds first. ' +
                TARGET_HELP +
                ' Returns the routine, including webUrl.',
            inputSchema: createRoutineToolArgsSchema,
            handler: async (args) =>
                runToolCaught({
                    toolName: 'create_routine',
                    logger,
                    action: async () => {
                        const created = await client.post<RoutineDetailResponse>({
                            path: basePath,
                            body: { name: args.name, description: args.description ?? null },
                        });

                        const routine =
                            args.exercises === undefined || args.exercises === null
                                ? created
                                : await putExercises(created.id, args.exercises);

                        return serializeToolResult({ body: withLinks(routine) });
                    },
                }),
        }),
        defineTool({
            methodName: 'UpdateRoutine',
            description:
                "Updates a routine's name or description, archives or restores it (archived true/false), " +
                'and/or replaces its whole exercise list. Omitted fields keep their stored value; pass an ' +
                'empty string for description to clear it. When exercises is given it REPLACES the list in ' +
                'the order given — send every slot you want to keep, so read the routine first. ' +
                TARGET_HELP,
            inputSchema: updateRoutineToolArgsSchema,
            handler: async (args) =>
                runToolCaught({
                    toolName: 'update_routine',
                    logger,
                    action: async () => {

                        let routine: RoutineDetailResponse | undefined;

                        if (Object.keys(patch).length > 0) {

                                path: `${basePath}/${args.routineId}`,
                                body: patch,
                            });
                        }

                        if (args.exercises !== undefined && args.exercises !== null) {
                            routine = await putExercises(args.routineId, args.exercises);
                        }

                        routine ??= await client.get<RoutineDetailResponse>({ path: `${basePath}/${args.routineId}` });

                        return serializeToolResult({ body: withLinks(routine) });
                    },
                }),
        }),

/**
 * Builds the PATCH body from only the keys the caller actually sent, so an omitted field keeps its
 * stored value. An empty description clears it, the same convention `item.tools.ts` uses.
 */
function buildRoutinePatch(args: {
    name?: string | null;
    description?: string | null;
    archived?: boolean | null;
}): Record<string, unknown> {
    const patch: Record<string, unknown> = {};

    if (args.name !== undefined && args.name !== null) patch['name'] = args.name;
    if (args.description !== undefined && args.description !== null) {
        patch['description'] = args.description.trim() === '' ? null : args.description;
    }
    if (args.archived !== undefined && args.archived !== null) patch['archived'] = args.archived;

    return patch;
}

/** Drops nullish keys so the API's own defaults (targetSets 3) apply, rather than sending nulls. */
function toSlotBody(input: RoutineExerciseToolInput): Record<string, unknown> {
    return Object.fromEntries(Object.entries(input).filter(([, value]) => value !== undefined && value !== null));
}
```

```ts
    exerciseCount: number;
    createdAt: string;
    updatedAt: string;
};

/** The exercise a slot points at — enough to render the row and pick an input widget. */
export type RoutineExerciseSummary = {
    id: string;
    name: string;
    trackingType: TrackingType;
    isCatalog: boolean;
    /** Set when the exercise was archived after being added; the slot stays, flagged. */
    archivedAt: string | null;
};

/** The editable part of a slot. Canonical units: kg, m, s. */
export type RoutineExerciseTargets = {
    targetSets: number;
    restSeconds: number | null;
    notes: string | null;
    targetReps: number | null;
    targetWeightKg: number | null;
    targetDurationSeconds: number | null;
    targetDistanceM: number | null;
};

/** One slot in a routine, in position order. */
export type RoutineExercise = RoutineExerciseTargets & {
    id: string;
    position: number;
    exercise: RoutineExerciseSummary;
};

export type RoutineDetail = Routine & { exercises: RoutineExercise[] };

export type SaveRoutineRequest = { name: string; description?: string | null };

export type PatchRoutineRequest = { name?: string; description?: string | null; archived?: boolean };

export type SaveRoutineExerciseRequest = Partial<RoutineExerciseTargets> & { exerciseId: string };

export type PatchRoutineExerciseRequest = Partial<RoutineExerciseTargets>;

/**
 * One line summarising a slot's targets — "3 × 8 · 62.5 kg · rest 1:30" — for the list row.
 * Only the targets that fit the exercise's tracking type are shown; the server rejects the rest.
 */
export function describeTargets(slot: RoutineExercise): string {
    const parts: string[] = [];

    const primary = primaryTarget(slot);
    parts.push(primary === null ? `${slot.targetSets} sets` : `${slot.targetSets} × ${primary}`);

    if (slot.exercise.trackingType === TrackingType.WeightReps && slot.targetWeightKg !== null) {
        parts.push(`${formatNumber(slot.targetWeightKg)} kg`);
    }

    if (slot.exercise.trackingType === TrackingType.DistanceTime && slot.targetDurationSeconds !== null) {
        parts.push(formatClock(slot.targetDurationSeconds));
    }

    if (slot.restSeconds !== null && slot.restSeconds > 0) parts.push(`rest ${formatClock(slot.restSeconds)}`);

    return parts.join(' · ');
}

/** Seconds as `m:ss`. */
export function formatClock(totalSeconds: number): string {
    const minutes = Math.floor(totalSeconds / 60);
    const seconds = totalSeconds % 60;
    return `${minutes}:${seconds.toString().padStart(2, '0')}`;
}

/** Metres as `400 m` or `5 km`, trimming trailing zeros. */
export function formatDistance(metres: number): string {
    return metres >= 1000 ? `${formatNumber(metres / 1000)} km` : `${formatNumber(metres)} m`;
}

function primaryTarget(slot: RoutineExercise): string | null {
    switch (slot.exercise.trackingType) {
        case TrackingType.WeightReps:
            return slot.targetReps === null ? null : String(slot.targetReps);
        case TrackingType.Duration:
            return slot.targetDurationSeconds === null ? null : formatClock(slot.targetDurationSeconds);
        case TrackingType.DistanceTime:
            return slot.targetDistanceM === null ? null : formatDistance(slot.targetDistanceM);
    }
}

function formatNumber(value: number): string {
    return Number.isInteger(value) ? String(value) : value.toFixed(2).replace(/\.?0+$/, '');
}
```

```ts
/**
 * The slot mutations all resolve to the whole routine, so each one writes that straight into the
 * detail query (no refetch flash) and then invalidates the list for its `exerciseCount`.
 */
function useRoutineSlotMutation<TVariables>({
    workspaceId,
    routineId,
    mutationFn,
}: {
    workspaceId: string;
    routineId: string;
    mutationFn: (variables: TVariables) => Promise<RoutineDetail>;
}): UseMutationResult<RoutineDetail, Error, TVariables> {
    const queryClient = useQueryClient();

    return useMutation({
        mutationFn,
        onSuccess: (routine) => {
            queryClient.setQueryData<RoutineDetail & { webUrl: string }>(
                ['routines', workspaceId, routineId],
                (previous) => (previous ? { ...previous, ...routine } : previous),
            );
            // Only the list queries (their third key element is the `{ search }` object): the
            // detail query was just written above and must not be refetched over.
            queryClient.invalidateQueries({
                queryKey: ['routines', workspaceId],
                predicate: (query) => query.queryKey.length === 3 && typeof query.queryKey[2] === 'object',
            });
        },
        onError: () => {
            queryClient.invalidateQueries({ queryKey: ['routines', workspaceId, routineId] });
        },
    });
}
```

```tsx
import { useEffect, useRef, useState } from 'react';
import { Reorder, useDragControls } from 'framer-motion';
import { GripVertical } from 'lucide-react';
import { Badge } from '@/components/ui/badge';
import { cn } from '@/lib/utils';
import { describeTargets, type RoutineExercise } from '@/models/routine';

type RoutineExerciseListProps = {
    slots: RoutineExercise[];
    selectedId: string | null;
    onSelect: (slot: RoutineExercise) => void;
    /** Fired once per drop with the complete new order. */
    onReorder: (orderedIds: string[]) => void;
};

/**
 * The routine's slots, drag-reorderable by the handle. Order is held locally while dragging and
 * committed once on drop, so a slow save does not fight the gesture.
 */
export function RoutineExerciseList({ slots, selectedId, onSelect, onReorder }: RoutineExerciseListProps): JSX.Element {
    const [order, setOrder] = useState<RoutineExercise[]>(slots);
    // `onDragEnd` closes over the render it was created in; the ref always has the latest order.
    const latest = useRef(order);
    latest.current = order;

    useEffect(() => {
        setOrder(slots);
    }, [slots]);

    const commit = (): void => {
        const ids = latest.current.map((slot) => slot.id);
        if (ids.some((id, index) => id !== slots[index]?.id)) onReorder(ids);
    };

    return (
        <Reorder.Group axis="y" values={order} onReorder={setOrder} className="space-y-2">
            {order.map((slot) => (
                <SlotRow
                    key={slot.id}
                    slot={slot}
                    isSelected={slot.id === selectedId}
                    onSelect={() => onSelect(slot)}
                    onDrop={commit}
                />
            ))}
        </Reorder.Group>
    );
}

function SlotRow({
    slot,
    isSelected,
    onSelect,
    onDrop,
}: {
    slot: RoutineExercise;
    isSelected: boolean;
    onSelect: () => void;
    onDrop: () => void;
}): JSX.Element {
    const controls = useDragControls();

    return (
        <Reorder.Item
            value={slot}
            dragListener={false}
            dragControls={controls}
            onDragEnd={onDrop}
            className={cn(
                'flex items-center gap-2 rounded-xl border bg-card pr-3 transition-colors',
                isSelected ? 'border-primary' : 'border-border',
            )}
        >
            <button
                type="button"
                aria-label="Drag to reorder"
                onPointerDown={(event) => controls.start(event)}
                className="flex h-14 w-10 shrink-0 cursor-grab touch-none items-center justify-center text-muted-foreground active:cursor-grabbing"
            >
                <GripVertical className="h-5 w-5" aria-hidden />
            </button>
            <button
                type="button"
                onClick={onSelect}
                className="flex min-h-[3.5rem] min-w-0 flex-1 flex-col justify-center py-2 text-left"
            >
                <span className="flex items-center gap-2">
                    <span className="truncate font-medium">{slot.exercise.name}</span>
                    {slot.exercise.archivedAt && (
                        <Badge variant="destructive" className="shrink-0">
                            Archived
                        </Badge>
                    )}
                </span>
                <span className="text-xs text-muted-foreground">{describeTargets(slot)}</span>
            </button>
        </Reorder.Item>
    );
}
```
